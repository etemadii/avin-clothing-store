# اطلس تشریحی و تکمیلی «دستگاه حرکتی» (زیست یازدهم، فصل ۳)

پروندهٔ ورودی: `C111216(2).PDF` (صفحات ۳۷ تا ۵۲ کتاب درسی). این مخزن خروجی زیر را تولید می کند:

| پرونده | محتوا |
|---|---|
| `Atlas_Dastgah_Harekaty.pdf` | **تحویل اصلی** (۶۶ صفحه): استخراج کامل تصاویر، ۲۲ لوح با درج ریز اطلاعات **روی خود تصویر**، برگهٔ تکمیل دانشگاهی/پزشکی برای هر لوح، نکات پیدا و پنهان، پیوند بالینی، ۵۲ تست چالشی، کلید فشرده و پاسخنامهٔ تشریحی، فهرست تصاویر و منابع |
| `Question_Bank_Challenge.pdf` | نسخهٔ مستقلِ تست ها و پاسخنامه (۲۰ صفحه، مناسب چاپ جداگانه) |
| `extracted_images/` | ۲۸ شیء تصویری جاسازی شده در PDF منبع، بدون تغییر پیکسل |
| `figure_crops/` | ۲۱ برش پرکیفیت از شکل ها همراه با برچسب های چاپی کتاب (پایهٔ حاشیه نویسی) |
| `assets/` | فونت وزیرمتن، فهرست تصاویر، نمودار بازسازی شدهٔ فعّالیت ۲ و لوح تطبیقی اسکلت جانوران |
| `biology_atlas/` | اسکریپت های استخراج (`extract_assets.py`)، محتوای علمی (`content_a/b/c.py`) و سازندهٔ PDF (`build_atlas.py`) |

## بازسازی خروجی
```bash
python3 -m pip install pymupdf pillow arabic-reshaper python-bidi
cp /tmp/arena-coding-uploads/C111216\(2\).PDF .   # یا قرار دادن پرونده در ریشه
python3 biology_atlas/extract_assets.py
python3 biology_atlas/build_atlas.py
```

## نکات روش شناسی
- تصاویر از اشیاء درون PDF استخراج شده اند؛ برش های شکل، برچسب های اصلی کتاب را هم در بر دارند تا وفاداری به چاپ حفظ شود.
- صفحهٔ ۵۲ کتاب تصویری ندارد، بنابراین «لوح تطبیقی سه نوع اسکلت» و «نمودار تراکم استخوان» از روی متن و منابع دانشگاهی بازسازی شده اند.
- منع درج شده در کتاب درسی برای طرح پرسش از شکل های ۱ و ۹ و اعداد جدول فعّالیت ۲ رعایت شده است: تست ها تحلیلی/مفهومی اند، نه حفظیات جانمایی و عدد خام.
- متن علمی با نگاه تخصصی نوشته شده و ساده سازی های کتاب (مانند نقش ATP در جداشدن سر میوزین، یا نسبت دادن درد تأخیری عضلانی به لاکتات) اصلاح شده اند.
